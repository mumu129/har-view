⚙️ 解密配置

「文件」标记者来自 decoders.js，「会话」标记者仅当前页面有效
不能与内置 / 文件中的算法冲突
选中模板会自动填充到下方代码框；密钥在「域名规则」中配置
签名：function(bytes, ctx) 或 async function(bytes, ctx)。 bytes 是 Uint8Array；ctx.keys 是该域名规则里配置的密钥对象。 可用全局：pako、TextDecoder、TextEncoder、atob、btoa、JSON、crypto。 返回值可以是字符串 / 对象 / Uint8Array。
「文件」标记者来自 rules.js，「会话」标记者仅当前页面有效
算法中通过 ctx.keys 读取此对象；不同域名可以配置不同密钥。 常用格式：AES-CBC/GCM 用 key（64 hex 字符）+ iv（32 hex 字符）；XOR 用整数 key。
·「生成 decoders.js 片段」= window.HAR_DECODERS = {...}; 整块结构，可直接替换 decoders.js 全文
·「生成 rules.js 片段」= [ {...}, {...} ] 纯数组，请替换 rules.js 里 window.HAR_RULES = [...] 的 [...] 部分
